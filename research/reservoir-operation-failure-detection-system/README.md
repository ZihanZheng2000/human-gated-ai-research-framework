## Project Aim

Design a human-AI interaction workflow for reservoir operation-stress/failure
analysis. The workflow should guide source selection, label definition,
detection, diagnosis, bounded model building, reviewer critique, human gates,
and report generation. A reservoir case is used only as a test example.

## Current Planning Unit

Demand/loss feasibility for hedging. The approved first test fixture is Hords
Creek Lake / Hords Creek Dam, Texas, with the USGS 10th-percentile low-storage
anomaly for 2011-09-30 to 2012-02-17, but hedging optimization now requires a
Demand-Loss Gate before Modeling.
